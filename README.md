## Tentang

> Menulis kode yang bersih, membangun arsitektur yang solid, dan memecahkan masalah nyata.

Saya mahasiswa IT di ITSNU Pekalongan yang berfokus pada pengembangan backend dengan ekosistem PHP dan Node.js. Saya senang merancang API, memodelkan database, dan menyusun logika bisnis yang rapi serta mudah dirawat.

- **Peran:** Junior Backend Developer
- **Lokasi:** Pekalongan, Jawa Tengah, Indonesia
- **Yang saya kerjakan:** RESTful API, autentikasi dan Role-Based Access Control, desain database relasional, serta integrasi layanan pihak ketiga
- **Terbuka untuk:** peluang kerja, magang, dan kolaborasi proyek
